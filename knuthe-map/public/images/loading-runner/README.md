# Loading Runner — 12프레임 달리기 스프라이트

`<LoadingRunner>` (components/shared/LoadingRunner.tsx) 가 참조하는 프레임 PNG 자산 폴더.

## 필요 파일

이 폴더에 정확히 12장의 PNG를 다음 이름으로 저장한다.

| 번호 | 파일명          | 포즈 (도안 라벨)         |
| ---- | --------------- | ------------------------ |
| 1    | `frame-01.png`  | 컨택트 (오른발)          |
| 2    | `frame-02.png`  | 다운                     |
| 3    | `frame-03.png`  | 패스 포지션              |
| 4    | `frame-04.png`  | 업                       |
| 5    | `frame-05.png`  | 익스텐션 (왼발)          |
| 6    | `frame-06.png`  | 컨택트 (왼발)            |
| 7    | `frame-07.png`  | 다운                     |
| 8    | `frame-08.png`  | 패스 포지션              |
| 9    | `frame-09.png`  | 업                       |
| 10   | `frame-10.png`  | 익스텐션 (오른발)        |
| 11   | `frame-11.png`  | 컨택트 (오른발)          |
| 12   | `frame-12.png`  | 다운 (다음 사이클로 연결) |

## 권장 스펙

- **해상도**: 정사각형 (예: `256×256` 또는 `512×512`)
- **여백**: 모든 프레임이 **동일한 캔버스 크기 + 동일한 발바닥 기준선(Y)** 을 가져야 함
  - 캐릭터 키 차이가 프레임마다 들쭉날쭉하면 제자리 달리기가 위아래로 튐
  - 도안 기준 "다운(2,7)"은 가장 낮고 "업(4,9)"은 가장 높음 → 이 수직 차이는 의도된 바운스라 OK
  - 발바닥 기준선만 일정하면 자연스러운 보행 진동으로 보임
- **수평 정렬**: 캐릭터의 무게 중심(허리)이 모든 프레임에서 캔버스 중앙 X 에 위치
  - 좌우로 흔들리면 제자리 달리기가 좌우로 떨림
- **배경**: 투명 (PNG-32, alpha 채널)
  - 다크/라이트 양쪽 테마 위에 동일하게 얹히기 위해 필수
  - 흰 배경으로 저장하면 다크모드에서 사각형이 도드라짐
- **그림자**: 캔버스 안에 포함하지 말 것 (컴포넌트가 별도 그림자를 처리)

## 도안에서 추출하는 방법

업로드한 도안 이미지(`런닝 애니메이션 12프레임 도안`) 기준:

1. 각 프레임은 라벨 아래에 위치한 캐릭터 영역만 잘라낸다.
2. 잘라낸 후 정사각형 캔버스 중앙에 배치, 발바닥 Y 좌표를 통일.
3. 알파 채널로 흰 배경 제거 (PhotoShop: 색상 범위 → 흰색 / Figma: Remove BG 플러그인).
4. 12장을 동일한 크기로 export.

## 참고

- 파일이 비어 있으면 `<LoadingRunner>` 는 아무것도 렌더하지 않고 (graceful fallback)
  주변 스켈레톤만 보인다.
- 새 프레임 디자인을 추가하려면 `frame-13.png` 부터 늘리고
  `LoadingRunner.tsx` 의 `FRAME_COUNT` 만 수정.
